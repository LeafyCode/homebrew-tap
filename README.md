# LeafyCode Homebrew tap

Homebrew casks for LeafyCode apps.

```sh
brew install leafycode/tap/kriyon
```

- **Kriyon**: a desktop command center for Claude Code. Source and releases:
  [LeafyCode/kriyon](https://github.com/LeafyCode/kriyon).

`Casks/kriyon.rb` is written by Kriyon's Publish workflow on every stable release. Don't edit it
by hand; a change here is overwritten by the next release. Report problems in the
[Kriyon repo](https://github.com/LeafyCode/kriyon/issues).
